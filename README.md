# Sunshine Cleaning Dashboard

Live business dashboard that connects to your Google Sheets data.

## Deploy to Vercel

Follow these steps to get your dashboard live:

### Method 1: Deploy via Vercel Dashboard (Easiest)

1. Go to [vercel.com](https://vercel.com) and sign in
2. Click "Add New" → "Project"
3. Click "Import Git Repository"
4. If you haven't connected GitHub yet:
   - Create a new GitHub repository
   - Upload this entire folder to GitHub
   - Connect your GitHub account to Vercel
5. Select your repository
6. Vercel will auto-detect Next.js - just click "Deploy"
7. Wait 1-2 minutes - your dashboard will be live!
8. Copy the URL and share with your team

### Method 2: Deploy via Vercel CLI (Alternative)

1. Install Vercel CLI: `npm i -g vercel`
2. Open terminal in this folder
3. Run: `vercel`
4. Follow the prompts
5. Your dashboard is live!

## How It Works

- Automatically fetches data from "SunshinesCleaning Master Sheet 2026"
- Updates in real-time when you click "Refresh Data"
- No manual data entry needed

## Features

- Total revenue and profit tracking
- Top clients by revenue
- Recent appointments
- Month-over-month growth
- Mobile responsive
